# Sentinel Trader AI

Production-oriented market intelligence app using live public market providers.

## Reality rules
- No fabricated prices, candles, signals or P&L.
- If providers return unusable data, the UI shows DATA UNAVAILABLE / NO TRADE.
- Technical decisions are deterministic multi-factor analysis, not a claim of guaranteed accuracy.
- Chart uploads are local browser previews unless a verified vision provider is configured; the app never pretends an image was analyzed.
- Public provider coverage is broad but cannot honestly be described as every security/exchange on Earth.

## Providers
- Binance Vision for supported USDT crypto pairs.
- Yahoo Finance for broad equities, indices, FX and commodities.
- Google News RSS for headline context.
